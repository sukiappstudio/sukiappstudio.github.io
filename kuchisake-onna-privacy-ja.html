プライバシーポリシー

施行日: 2026-11-07

Suki App Studio（以下「当方」）は、Kuchisake-onna: Am I Pretty? モバイルアプリ（以下「本アプリ」）を通じて取り扱われる個人情報の管理者です。本ポリシーでは、どのような情報が、誰によって、何のために取り扱われるか、また利用者が選択できる事項について説明します。

1. 概要

本アプリにはユーザーアカウントがなく、当方は本アプリのためのサーバーを運営していません。利用者の設定、進行中の帰り道および過去の帰り道の記録は利用者の端末にのみ保存され、当方に送信されることはありません。本アプリはネットワーク接続なしで動作しますが、広告と当方のほかのアプリの一覧は例外です。広告は Google AdMob により提供され、第2条に記載する情報を収集します。当方のほかのアプリの一覧は、本アプリが当方のウェブサイトからダウンロードします。当方が本アプリ自体から受け取る情報はなく、利用者がメールで送信した内容のみを受け取ります。

2. 取り扱う情報

設定（端末内のみ）。サウンド、バイブレーション、女の声のオン・オフ、および言語。

帰り道（端末内のみ）。利用者が歩いている間、電話の操作などで中断された帰り道を中断した場所から続けられるよう、本アプリはその夜の番号と利用者のすべての選択（一歩ごと、答えごと、逃走中のスワイプごと）を保存します。これらは帰り道が終わると削除されます。過去の帰り道の記録には、夜ごとに、日付、通り、物語の中の時刻と天気、利用者の答え、答えるまでにかかった時間、およびその夜がどのように終わったかが保存されます。記録は本アプリ内で消去できます。歩き終えた帰り道の回数は、広告の表示間隔の調整にも使用されます。

タッチ操作と時間。本アプリは、物語を進めるためにのみ、利用者のタップやスワイプ、および答えるまでにかかる時間を読み取ります。それ以外に、利用者が本アプリをどのように使用するかについては記録しません。

女の声。女のせりふは、端末上で動作するスマートフォン自体の音声読み上げ（TTS）エンジンによって読み上げられ、本アプリがそれをささやき声に変えます。このエンジンはその提供者（通常は端末メーカーまたは Google）のものであり、その提供者のプライバシーポリシーが適用されます。本アプリがエンジンに渡すのは読み上げる文のみです。音声は本アプリのキャッシュ内の一時ファイルに生成され、直ちに削除されます。女の声は設定でオフにできます。

シェアカード。利用者が「シェア」をタップすると、本アプリは結末（その夜、通り、利用者がしたこと）の画像を本アプリの非公開キャッシュに描画し、端末の共有シートに渡します。画像は利用者が送信先として選んだ場所にのみ送られます。

当方のほかのアプリ。本アプリは、結末画面および「Suki App Studioのほかのアプリ」に表示するため、当方のほかのホラーアプリの一覧とアイコンを当方のウェブサイト（sukiappstudio.github.io、GitHub がホスティング）から1日に最大1回ダウンロードします。通常のウェブリクエストと同様に、ホストは利用者の IP アドレスと基本的なリクエスト情報を受け取りますが、利用者に関する識別子や情報は送信されません。「入手」の代わりに「開く」を表示するため、本アプリはそれらのアプリがインストールされているかを端末上で確認しますが、その結果が端末の外に出ることはありません。

広告データ（Google が収集）。Google Mobile Ads SDK は次の3つの方法で広告を表示し、通りの上、女の問いかけの最中、逃走中に表示することはありません：最初の帰り道を歩き終えた後にホーム画面と記録画面の下部に表示されるバナー、「歩きはじめる」を押したときにときどき表示される全画面広告（多くても2回に1回、セッションの最初には表示されず、少なくとも2分の間隔を空けます）、そして帰り道の前に傘（逃走中に1回の追加チャンス）を持っていくため、または友だちに決まりを聞く（その夜に通用する対処法を1つ）ために、利用者が自ら視聴を選んだ場合にのみ表示される短い動画です。同 SDK は、広告、効果測定、分析および不正防止のために、広告 ID その他の端末識別子、IP アドレス（おおよその位置情報の推定に使用されます）、端末およびアプリの情報、診断情報、ならびに広告とのやり取りに関する情報を収集します。法律で求められる場合には、広告がリクエストされる前に Google の同意メッセージ（User Messaging Platform）が利用者の選択を確認します。Google LLC およびそのパートナーは、https://policies.google.com/technologies/partner-sites および https://policies.google.com/privacy に記載されているとおりにこの情報を取り扱います。本アプリにはアプリ内課金および分析 SDK はありません。

権限。ネットワークアクセス（広告および当方のアプリの一覧）とバイブレーション（女が近づくときと問いかけのとき。設定で切り替え可能）。本アプリは、位置情報、カメラ、マイク、連絡先、写真、ファイルまたは通知を使用しません。

メール。利用者が当方にメールを送信した場合、当方は利用者のメールアドレスとメッセージの内容を受け取り、返信のためにのみ使用します。

3. 利用目的および法的根拠

帰り道、記録および設定の保存と物語の進行：利用者が求める機能の提供、および正常に動作するアプリを提供するという当方の正当な利益。

広告：法律で求められる場合は利用者の同意（たとえば欧州経済領域、英国およびスイスでは Google の同意メッセージを通じて取得）、それ以外の場合は本アプリを無料で提供し続けるという当方の正当な利益。

当方のほかのアプリの表示：利用者にそれらのアプリを知らせるという当方の正当な利益。

メールへの返信：利用者に回答し、お問い合わせに対応するという当方の正当な利益。

4. 提供先および国外移転

当方は個人情報を販売しません。当方は、利用者がメールで送信した内容を除き、第2条に記載する情報を一切受け取りません。また、Google Play から、利用者を特定できない集計統計およびクラッシュレポートが当方に提供されます。

米国および Google とその広告パートナーが事業を行うその他の国に所在する Google LLC は、広告を表示し効果を測定するため、第2条に記載する広告データを暗号化された接続を通じて利用者の端末から直接受け取ります。Google は、標準契約条項および該当する場合は EU-米国データプライバシーフレームワークを含む、自社のポリシーに記載された保護措置のもとでこの情報を取り扱います。GitHub, Inc.（米国）は当方のウェブサイトをホスティングし、上記のリクエスト情報を受け取ります。当方のメールは Google（Gmail）がホスティングしています。一部の法律では、パーソナライズ広告の表示は、クロスコンテキスト行動広告のための「共有」とみなされます。利用者は第6条に記載する方法でこれをオプトアウトできます。

5. 保存期間

記録と設定は、利用者がそれらを消去するか、本アプリのデータを消去するか、本アプリをアンインストールするまで端末に残ります。本アプリは Android の自動バックアップを使用します。端末でバックアップがオンになっている場合、これらのデータはそのバックアップが削除されるまで利用者ご本人の Google アカウントのバックアップに含まれることがあり、データを移行する際に新しい端末へ移されることがあります。シェアカードは、Android または利用者がキャッシュを消去するまで本アプリのキャッシュに残ります。当方は、法律でより長い保存が求められない限り、メッセージへの対応に必要な期間に限りメールを保存します。Google は自社のポリシーに従って広告データを保存します。

6. 利用者の選択と権利

端末内のデータ：本アプリ内で記録を消去するか、本アプリのデータを消去またはアンインストールすることですべてを削除できます。サウンド、バイブレーションおよび女の声は、本アプリの設定でオン・オフを切り替えられます。

広告に関する選択：本アプリの設定にある「広告のプライバシー設定」（法律で求められる場合に表示されます）を開くと、同意を変更または撤回できます。広告 ID のリセットまたは削除、および広告のパーソナライズの無効化は、Android の設定（端末により Google > 広告、またはプライバシー > 広告）で行えます。

お住まいの地域によっては、利用者は、個人情報の開示、訂正、削除およびポータビリティを求める権利、取り扱いの制限または取り扱いへの異議を求める権利、いつでも同意を撤回する権利、ならびにデータ保護当局に苦情を申し立てる権利を有します。当方はいかなるサーバーにも利用者の個人情報を保有していないため、ほとんどのご要望は利用者ご自身の端末上で対応できます。Google が保有する情報については、Google のツールをご利用ください。利用者はいつでも下記の連絡先から当方にお問い合わせいただくことができ、当方は法律で定められた期間内に回答します。

大韓民国：取り扱う個人情報の項目、利用目的および保存期間は、第2条、第3条および第5条に記載するとおりです。個人情報は Google LLC（米国および同社が事業を行うその他の国）に対してのみ国外に提供または移転されます。移転する項目：第2条の広告データ、目的：広告、効果測定および不正防止、時期および方法：広告の表示中にネットワークを通じて送信、保存期間：Google のポリシーに従います。利用者は、広告への同意を拒否するか広告のパーソナライズを無効にすることでこの移転を拒否できます。その場合、パーソナライズ広告は表示されません。当方のメールサービス（Gmail）は Google LLC に、ウェブサイトのホスティングは GitHub, Inc. に委託しています。自動収集装置：本アプリは Cookie を使用しません。広告 SDK は広告 ID を使用し、広告 ID は第6条に記載する方法でリセットまたは削除できます。個人情報は本アプリのデータを消去することにより、メールは当方のメールボックスから削除することにより破棄されます。個人情報保護責任者：Suki App Studio 代表、sukiappstudio@gmail.com。利用者は、個人情報侵害申告センター（https://privacy.kisa.or.kr、118）または個人情報紛争調停委員会（https://www.kopico.go.kr、1833-6972）に支援を求めることもできます。14歳未満の児童は、法定代理人の同意なしに本アプリを利用することはできません。

米国（カリフォルニア州を含む）：当方は金銭を対価として個人情報を販売しません。利用者は第6条の選択方法により、クロスコンテキスト行動広告のための「共有」をオプトアウトできます。当方は、利用者の特性を推測するためにセンシティブな個人情報を使用せず、利用者が権利を行使したことを理由に差別することはありません。

日本：当方は個人情報の保護に関する法律に従って個人情報を取り扱います。Google が受け取る広告データは、第4条に記載するとおり、米国その他の国で取り扱われることがあります。

インド：利用者は、2023年デジタル個人データ保護法（Digital Personal Data Protection Act, 2023）に定める権利を有し、これには代理人を指名する権利、および下記の連絡先を通じて苦情の救済を受ける権利が含まれます。
