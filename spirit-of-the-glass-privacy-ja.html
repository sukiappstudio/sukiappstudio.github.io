プライバシーポリシー

施行日: 2026-10-25

Suki App Studio（以下「当社」）は、グラスの霊モバイルアプリ（以下「本アプリ」）を通じて処理される個人情報の管理者です。本ポリシーは、どの情報が誰によってどの目的で処理されるか、また利用者が選択できる事項を説明します。

1. 概要

本アプリにはユーザーアカウントがなく、当社は本アプリのためのサーバーを運営していません。設定と、過去のゲームの記録（入力した質問とグラスが綴った答え）は利用者の端末にのみ保存され、当社に送信されることはありません。本アプリは広告と「ほかの儀式」一覧を除きネットワーク接続なしで動作します。広告は Google AdMob が提供し、第2条に記載のデータを収集します。「ほかの儀式」一覧は当社のウェブサイトからダウンロードされます。当社は本アプリ自体からは何も受け取らず、利用者がメールで送るものだけを受け取ります。

2. 取り扱う情報

設定（端末内のみ）。サウンド、バイブレーション、言語、選んだボード。

ゲームの記録（端末内のみ）。終えたゲームの回数と最後のゲームがどのように終わったか（例：グラスを円の中の家へ帰したかどうか。ゲームを終えずに離れた場合、次のゲームはグラスがすでに動いている状態で始まります）、および全画面広告の間隔を空けるために使われるカウンター。記録：ゲームごとの日時、使ったボード、グラスにのせた指の数、終わり方、指がグラスから離れた回数、入力した質問とグラスが綴った答え（直近60回まで）。進行中のゲームは下書きとして端末に保存されるため、途中で中断したゲームも記録に残ります。「記録」画面で一件ずつ削除するか、「記録を燃やす」で記録全体を削除できます。ゲームの内容が端末の外に出るのは、利用者が「共有」を押したときだけです。その場合、本アプリはゲームを画像に描き、本アプリのキャッシュに一時ファイルとして保存して、Android の共有画面で利用者が選んだアプリに渡します。当社がそれを受け取ることはありません。

質問とタッチ。入力した文字と、画面上でグラスにのせた指の位置（1台のスマートフォンで1〜4人が一緒に遊べます）は、ゲームを進める（答えを決め、グラスを動かす）ためにのみ端末内で処理されます。質問と答えは上記のとおり端末内の記録に保存され、指の位置は保存されません。どこにも送信されません。本アプリには音声入力がなく、マイクやカメラを使用しません。

「ほかの儀式」一覧。当社のほかのアプリを紹介するため、本アプリは1日に最大1回、当社のウェブサイト sukiappstudio.github.io からアプリの一覧とアイコンをダウンロードします。ウェブサイトは GitHub Pages でホストされているため、サイトのホストである GitHub, Inc. が利用者の IP アドレスと通常の技術的なリクエストデータ（リクエストの日時、アプリやブラウザの種類など）を受け取ります。このリクエストには、利用者や利用者による本アプリの利用に関する情報は一切含まれません。その後、本アプリはすでにインストールされているアプリを勧めないよう、一覧のうちどのアプリがインストール済みかを端末内で確認します。この結果が端末の外に出ることはありません。

広告データ（Google とそのパートナーが収集）。Google Mobile Ads SDK は、ゲームの最中には決して広告を表示せず、次の三つの方法でのみ表示します：最初のゲームを終えた後のホーム画面と結果画面下部のバナー、新しいゲームを始めるときに時々表示される全画面広告（起動後最初のゲームの前には表示されず、2回目の開始ごとに最大1回、少なくとも2分の間隔を空け、1日数回まで）、そして新しい蝋燭を灯してさらに三つ質問するために利用者が自ら選んだ場合にのみ再生される短い動画広告。SDK は広告、測定、分析、不正防止のために、広告 ID やその他の端末識別子、IP アドレス（おおよその位置情報が導かれます）、端末・アプリ情報、診断情報、広告への操作を収集します。Google はメディエーションを通じてパートナーネットワークに広告をリクエストすることがあり、その一つである Unity Technologies（Unity Ads）は、https://unity.com/legal/privacy-policy のプライバシーポリシーに記載のとおり広告データを受け取ることがあります。法律が求める地域では、広告を要求する前に Google の同意メッセージ（User Messaging Platform）が利用者の選択を尋ねます。Google LLC とそのパートナーは https://policies.google.com/technologies/partner-sites および https://policies.google.com/privacy に記載のとおりこのデータを処理します。本アプリにはアプリ内課金も分析 SDK もありません。

権限。本アプリが求める権限は、ネットワークアクセス（広告と「ほかの儀式」一覧の表示のため）とバイブレーション（グラスの動きなどの効果に使用、「設定」で無効化可能）のみで、そのほかの権限は求めません。位置情報、カメラ、マイク、連絡先、写真、ファイルは使用しません。

メール。利用者が当社にメールを送ると、当社はメールアドレスと内容を受け取り、返信のためにのみ使用します。

3. 利用目的および法的根拠

記録と設定の保存、ゲームの進行および「ほかの儀式」一覧の表示：利用者が求める機能の提供、および正常に動作するアプリを提供するという当方の正当な利益。

広告：法律で求められる場合は利用者の同意（例えば欧州経済領域、英国およびスイスでは Google の同意メッセージを通じて取得）、それ以外の場合は本アプリを無料で提供し続けるという当方の正当な利益。

メールへの返信：利用者に回答し、お問い合わせに対応するという当方の正当な利益。

4. 提供先および国外移転

当方は個人情報を販売しません。当方は、利用者がメールで送信した内容を除き、第2条に記載する情報を一切受け取りません。また、Google Play から、利用者を特定しない集計統計およびクラッシュレポートが当方に提供されます。

米国および Google とその広告パートナーが事業を行うその他の国に所在する Google LLC は、広告の表示および効果測定のため、第2条に記載する広告データを暗号化された接続を通じて利用者の端末から直接受け取ります。Unity Technologies（米国その他の国）などのメディエーションパートナーは、同じ目的のために Google のメディエーションを通じて広告データを受け取ることがあります。Google は、標準契約条項および該当する場合には EU-米国データプライバシーフレームワークを含む、自社のポリシーに記載された保護措置のもとでこれを取り扱います。当方のウェブサイトをホストする GitHub, Inc.（米国）は、本アプリが「ほかの儀式」一覧をダウンロードする際に、第2条に記載するリクエストデータを受け取ります。当方のメールは Google（Gmail）によりホストされています。一部の法律では、パーソナライズド広告の表示は、クロスコンテキスト行動広告のための「共有」として扱われます。利用者は第6条に記載する方法でこれをオプトアウトできます。

5. 保存期間

記録と設定は、利用者が本アプリ内で削除するか、本アプリのデータを消去するか、本アプリをアンインストールするまで端末に残ります。記録は直近60回のゲームまで保存され、それより古いものは自動的に削除されます。共有用に作成した画像は本アプリのキャッシュ内の一時ファイルで、Android がいつでも消去することがあります。本アプリは Android の自動バックアップを使用します。端末でバックアップがオンになっている場合、これらのデータはバックアップが削除されるまで利用者自身の Google アカウント内のバックアップに含まれることがあり、データを移行する際に新しい端末へ移されることがあります。当方は、法律でより長い保存が求められる場合を除き、メッセージへの対応に必要な期間に限りメールを保存します。Google、その広告パートナーおよび GitHub は、受け取ったデータを各社のポリシーに従って保存します。

6. 利用者の選択と権利

端末内のデータ：「記録」画面で一件ずつ、または記録全体（「記録を燃やす」）を削除できます。また、本アプリのデータを消去するか本アプリをアンインストールすることで、すべてを削除できます。サウンドとバイブレーションは本アプリの設定でオン・オフを切り替えられます。

広告に関する選択：本アプリの設定にある「広告のプライバシー設定」（法律で求められる場合に表示されます）を開き、同意の変更や撤回ができます。広告 ID のリセットや削除、広告のカスタマイズのオフは、Android の設定（端末により Google > 広告、またはプライバシー > 広告）から行えます。

お住まいの地域によっては、利用者は個人情報の開示、訂正、削除およびデータポータビリティを求める権利、取り扱いの制限を求め、または取り扱いに異議を述べる権利、いつでも同意を撤回する権利、ならびにデータ保護当局に苦情を申し立てる権利を有します。当方はいかなるサーバーにも利用者の個人情報を保有していないため、ほとんどの請求は利用者自身の端末上で実現できます。Google が保有するデータについては Google のツールをご利用ください。利用者はいつでも下記の連絡先までお問い合わせいただくことができ、当方は法律で定められた期間内に回答します。

大韓民国：取り扱う項目、目的および保存期間は第2条、第3条および第5条に記載のとおりです。個人情報は次の場合に限り国外へ提供または移転されます。(1) Google LLC（米国および同社が事業を行うその他の国）、ならびに Google のメディエーションを通じて Unity Technologies（米国その他の国）へ：移転する項目：第2条の広告データ、目的：広告、効果測定および不正防止、時期および方法：広告のリクエスト中または表示中にネットワークを通じて送信、保存期間：各社のポリシーによります。利用者は、広告への同意を拒否するか広告のカスタマイズをオフにすることでこの移転を拒否できます。その場合、パーソナライズド広告は表示されません。(2) 当方のウェブサイトのホストである GitHub, Inc.（米国）へ：IP アドレスおよびリクエストデータ、時期および方法：「ほかの儀式」一覧のダウンロード時（1日に最大1回）にネットワークを通じて送信、保存期間：GitHub のポリシーによります。利用者は、「ほかの儀式」画面を開かないか、ネットワーク接続なしで本アプリを利用することでこの移転を拒否できます。その場合、当方のほかのアプリの一覧は表示されません。当方のメールサービス（Gmail）は Google LLC に委託しています。自動的に収集される情報：本アプリは Cookie を使用しません。広告 SDK は広告 ID を使用し、利用者は第6条に記載する方法でこれをリセットまたは削除できます。個人情報は「記録」画面で削除するか本アプリのデータを削除することにより、メールは当方のメールボックスから削除することにより破棄されます。個人情報保護責任者：Suki App Studio の代表者、sukiappstudio@gmail.com。また、個人情報侵害申告センター（https://privacy.kisa.or.kr、118）または個人情報紛争調停委員会（https://www.kopico.go.kr、1833-6972）に支援を求めることもできます。14歳未満の児童は、法定代理人の同意なしに本アプリを利用することはできません。

8. 児童

本アプリは13歳未満の児童を対象としていません。居住地において自身の個人データの取り扱いに同意できる年齢（例えば大韓民国では14歳、一部の欧州諸国では最大16歳）に達していない方は、親または保護者の同意がある場合に限り本アプリを利用できます。当方は児童の個人情報を故意に取り扱うことはありません。児童がそのような同意なく本アプリを利用したと思われる場合は、当方までご連絡ください。

9. セキュリティ

本アプリは、Android が他のアプリから保護する非公開ストレージにデータを保存し、広告 SDK と「ほかの儀式」一覧のダウンロードは暗号化された接続を使用します。
